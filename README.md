# 林间的个人网站

一个中文个人创作者门户，提供作品集、博客、用户注册登录、社区发帖与用户私信、网站目录和实用小工具。

## 本地启动

1. 安装 Node.js 20 或更新版本。
2. 在项目根目录运行 `npm install`。
3. 在第一个终端运行 `npm run server`，启动 API 和 SQLite 数据库。
4. 在第二个终端运行 `npm run dev`，再打开 Vite 显示的本地地址。

正式构建后，运行 `npm run build` 和 `npm start` 可以由同一个服务提供页面与 API。论坛账户和消息保存在 `server/data.db`。部署前请设置强随机 `JWT_SECRET` 环境变量。

## 页面

- 首页：项目展示、文章精选、社区入口和个人介绍
- 作品：项目卡片与介绍
- 博客：文章列表（当前示例内容）
- 论坛：注册、登录、发布帖子、私信
- 网站目录：常用网站链接
- 小工具：当地时间、短句、饮水计数、专注计时器界面

论坛帖子与私信使用 SQLite 保存。作品和博客目前是展示用示例内容；小工具页面提供客户端交互。
